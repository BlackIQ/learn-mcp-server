# Learn MCP Server

For the project **[Rachel](https://github.com/BlackIQ/Rachel)**, I had to learn what is **[MCP](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)** and make something with it.

So, tried to create a **Server** and learn to how can I also use it as **Client**. This is the Server side, Client side is at [Learn MCP Client](https://github.com/BlackIQ/learn-mcp-client).

## Tech

- MCP Server: Where MCP Client communicates with
- UV: Package Manager

## Tools

- Say Hi: Get a name and say hello to it
- Get Weather: Fetch weather from [Weather API](https://weatherapi.com)

## Let's make it happen

First we should setup the project, then we can run it.

### Setup

1. First clone the repo:

```bash
https://github.com/BlackIQ/learn-mcp-server
```

2. Get inside it:

```bash
cd learn-mcp-server
```

3. Install packages:

```bash
uv sync
```

4. Get API Key from [Weather API](https://weatherapi.com).

5. Create or copy the `.env.example` file:

```bash
cp .env.example .env
```

6. Open and edit it.
